## Fixed findings

- SQLite authentication rejects stale verified credentials after concurrent password/role changes. Credential versions survive upgrades/exports, permissions are rechecked during protected writes after body upload, and last-owner guards are transactional.
- Project/task dates require valid ISO dates or blanks. Optional relationship IDs consistently reject false/numeric values.
- Direct negative requirements such as “Don’t add payment” and “Do not remove payment” become constraints. Deduplication preserves repeated word order.
- Large valid requests produce bounded, persistable diagnostics with explicit omission warnings. Token/posting indexes avoid repeated parsing while preserving deterministic ordering.
- Requirement, invoice and proposal Markdown exports escape user text. Project exports describe saved agency records accurately. The commercial-export test failed on raw HTML before the fix and passed afterward.
- Authentication transitions reset filters/search. Declined proposals are consistently excluded from reports. Malformed pending-journal metadata is archived for recovery. Viewer copy fallback dialogs close without writing a revision.
